# Arcane Native Build Gate — تعليمات بالعربية

هذه تجربة مستقلة في المستودع \`achirothmane/arcane-native-build-gate\`، ولا تُعد منتجًا تجاريًا.

تفحص GitHub Actions ثلاثة إصدارات مثبّتة من Arcane. لكل إصدار، تنزّل المصادر العامة في مساحة مؤقتة، تثبّت \`pnpm\` وتبعيات المشروع، وتشغّل فحص Svelte والبناء الأصلي قبل إجراء تعديل. إذا لم ينجح البناء الأصلي تسجّل \`BASELINE_FAILED\`. ثم تتحقق آلية التعديل من commit وبصمات Git blob وتطبّق تغييرًا حتميًا معروفًا وتعيد الفحص والبناء.

يمكن قراءة تشغيلات التجربة في [GitHub Actions](https://github.com/achirothmane/arcane-native-build-gate/actions). السجلات وملفات diff وmanifest تُحفظ في Artifacts عندما يسمح التنفيذ بذلك.

**معنى النجاح محدود**: \`BUILD_PASS_ONLY_RUNTIME_NOT_TESTED\` يعني نجاح البناء فقط، وليس إصلاح التداخل أو القص داخل تطبيق يعمل ولا إثبات التفوق على المنافسين. وعند فشل تثبيت التبعيات، هذا قيد بناء أصلي، ولا يجوز وصفه بفشل الإصلاح نفسه.

المستودع لا يرفع شيفرة إلى Arcane، ولا يرسل Pull Request، ولا ينشر إصدارات. لا تُضاف أسرار أو بيانات إنتاجية إلى هذا الاختبار.

**الحكم التجاري الحالي: TEST ONLY / NO RELEASE**.
